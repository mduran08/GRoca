-------
--> TPV
-------

TPVIMP.DAT, s'ha de comprimir en TPVIMP.ZIP
Els registres son de llargada variable
Els números son cuadrats a la dreta i sense zeros davant

EX:

00       6BOF TPV IMPORT FILES
014012700963000  000001         ZE-30 JUW CINTA SENSE CAPSA                                      290.00                       N    12.000
013390077045864  000002         ZE-60 JUW CINTA SENSE CAPSA                                      800.00                       N   -19.000
0112345678       000003         ZE-90 JUW CINTA SENSE CAPSA                                      230.00                       N   643.000
99       6EOF TPV IMPORT FILES

-------

Els registres son de llargada variable
Els números son cuadrats a la dreta i sense zeros davant
